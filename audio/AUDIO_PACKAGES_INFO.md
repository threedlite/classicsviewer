# Available Audio Packages

## Package 1: David Chamberlain's Homer Reading
- **File**: `homer_iliad_chamberlain_audio.zip`
- **Format**: MP4 audio files
- **Content**: Homer's Iliad
- **Source**: https://hypotactic.com/my-reading-of-homer-work-in-progress/
- **License**: CC-BY © 2016, 2017 by David Chamberlain
- **Type**: Human voice recitation with proper Ancient Greek pronunciation
- **Description**: Professional recording of Homer's Iliad by a classics scholar

## Package 2: Lyresong MIDI Generation
- **File**: `homer_iliad_lyresong.zip` (1.2MB)
- **Format**: MIDI files
- **Content**: Homer's Iliad Book 1, lines 1-10
- **Source**: https://github.com/threedlite/lyresong
- **Type**: Computer-generated musical interpretation
- **Description**: Algorithmic conversion of Ancient Greek text to musical notation

## Import Instructions

1. Open the app and navigate to Settings → Manage Audio
2. Import first package: `homer_iliad_chamberlain_audio.zip`
   - Package will be named "homer_iliad_chamberlain_audio"
   - Set as active by default
3. Import second package: `homer_iliad_lyresong.zip`
   - Package will be named "homer_iliad_lyresong"
   - Can switch between packages using radio buttons

## Package Structure

Both packages follow the required structure:
```
Homer/Iliad/book_1/line_X.{mp4|mid}
```
